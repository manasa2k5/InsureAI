# 🚀 InsureAI – Smart Insurance Management System

InsureAI is a full-stack intelligent insurance platform designed to automate customer-agent interaction, appointment scheduling, and policy recommendations using smart decision-making logic.

---

## 🔥 Key Features

* 🔐 Secure Authentication using JWT & Spring Security
* 🤖 Smart Agent Matching based on expertise and location
* 📅 Appointment Booking System with scheduling
* ⚡ Auto Booking (automatic agent assignment + appointment creation)
* 📊 Dashboard with real-time appointment statistics
* 📌 Appointment Management (Booked, Completed, Cancelled)
* 🧠 Policy Recommendation System based on user inputs
* 🔄 Full-stack integration with REST APIs

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash id="insure1"
git clone https://github.com/manasa2k5/InsureAI
cd InsureAI
```

---

## 🚀 Run Backend (Spring Boot)

### 👉 Using Maven Wrapper (Recommended for Windows)

```bash id="insure2"
.\mvnw.cmd spring-boot:run
```

---

### 👉 Alternative (If Maven Installed)

```bash id="insure3"
mvn spring-boot:run
```

---

### 👉 Run using JAR

```bash id="insure4"
mvn clean package
java -jar target/*.jar
```

---

## 🌐 Run Frontend

Open `index.html` in browser

OR use Live Server (VS Code)
